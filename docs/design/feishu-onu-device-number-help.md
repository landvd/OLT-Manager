# Feishu ONU 设备号与帮助合同

## 当前实现

- ONU 详情卡片仅在只读数据服务候选中明确提供字符串字段 `deviceNumber` 时显示“ONU 设备号”。
- `serialNumber`（ONU 序列号/SN）不会回填为 `deviceNumber`，避免把两个现场字段混淆。
- Feishu application 对候选做显式字段投影，只保留用户查询所需的非敏感字段；未知字段不会进入卡片或回调绑定。
- `帮助`、`help`、`使用帮助`、`查询帮助`、`命令帮助`、`指令`由本地 application 处理，不调用语言 provider 或远端数据服务。

## 设备号查询边界

设备号查询使用独立的只读 Gateway seam：

```text
gateway.queryUsersByDeviceNumber({ value, oltIds, limit })
```

当前生产只读 Gateway 已提供 `queryUsersByDeviceNumber`，设备号搜索不会退回调用 `find_by_sn`，也不会把序列号误当设备号。若宿主注入的 Gateway 缺少该方法，Feishu 仍会安全返回未接入提示。

本地语言解析器优先识别裸的 17 至 24 位数字，并识别 `设备号`、`设备编号`、`设备号码`、`设备ID` 后跟数字或字母数字值的输入；例如 `1523001222900197753` 和 `设备号：1523001222900197753` 使用同一个设备号查询值。Gateway 层还会去除常见的“查询/是/为”前缀，避免自然语言标签参与精确匹配。

## 帮助示例与场景化合同

默认查询顺序为：姓名 → 手机 → LOID → 设备号 → 装机地址。前一字段没有匹配时继续查询下一字段；全部字段没有匹配，返回四维场景化帮助指南而不是简单的“没有找到匹配项”。

### 四维场景化帮助结构：
1. **日常查单**：支持姓名（如 `张三`）、手机号（11位或8位固话）、LOID（如 `LOID123456`）、设备号（17-24位）、装机地址（如 `厚街三屯中路12号`）。
2. **告警与抢修定位**：
   - 支持 `OLT IP + board/pon` 逆向定位一级地址（如 `172.19.104.101 3/4`、`104.101 3/4`），自动提取光交箱或村庄覆盖范围；
   - 支持村级光功率抢修验收定界（如 `光功率 塘尾村`），自动输出主干熔接质量评级并抓取最差 Top 3 弱光用户；
   - 支持掉电/断纤故障定位（如 `掉电 汀山村`、`LOS 赤岭村`）。
3. **Pi 专家问答**：发送专业排障问题或 `@机器人`（如 `华为LOS怎么排查`、`流氓ONU隔离命令`、`光衰门限标准`），由内置 Pi Agent 提供专家建议。
4. **装维门限速查表**：直观展示光功率合格线（-8.0 ~ -24.0 dBm）、弱光预警线（-24.0 ~ -27.0 dBm）与严重故障线（< -27.0 dBm）。

## PON 逆向一级地址与抢修定界边界

1. **PON 口逆向查一级地址**：
   - 使用 Gateway `findLedgerEntriesByPonPort` 与 `findVillageOrAreaByPonPort`；
   - 纯本地 SQLite 台账查询，聚合出该 PON 口最高频的一级光交箱/村庄地址、在线/离线用户数及平均光衰；
   - 严禁向 OLT 执行任何写操作。
2. **村级光功率抢修定界与抽样合同**：
   - **定界逻辑以“抢修前后光衰突变恶化量”为核心**：计算差值 $\Delta = \text{当前} - \text{历史}$。仅当检测到 $\Delta \le -2.0 \text{ dB}$（损耗突增 2dB 以上）时作为抢修劣化恶化预警；全村各口平稳时给出“🟢 主干熔接质量优秀，可放心封盒”结论，彻底隐去常年老弱光用户列表，避免现场误解；
   - **同 PON 口在线用户自动回退抽样**：当匹配目标村名的特定用户碰巧关机离线时，系统自动回退至该 PON 口上已有的其他在线用户抽样（同一 PON 口共享物理主干光缆与分光器，其光衰 100% 反映主干通断与熔接质量），杜绝跨村边界口误判为“未完成”；
   - **无历史实时合格放行**：当抽测到的用户缺乏 7 天历史快照时，只要实时光衰处于合格门限（$>-27.0 \text{ dBm}$），直接判定为正常通畅，杜绝虚报“未完成”；
   - **用户档案地址智能推导**：当本地 PON 台账（`pon_ports`）未录入该口地址时，系统自动从该口已有用户的档案中提炼代表性门牌或村庄地址，杜绝卡片展示“未提供”；
   - 严禁向 OLT 执行任何写操作。
3. **交互卡片直观性**：
   - 仪表盘采用红绿灯视觉，掉电使用 `⚡ DyingGasp`，断纤使用 `✂️ LOS`；
   - 用户与联系人电话号码转换为 `[电话](tel:电话)` Markdown 格式，移动端点击即拨号。

本变更不连接现场、不执行 OLT 命令、不刷新远端数据，也不持久化或返回凭据、Cookie、token、CUID、FDN 或原始远端响应。
