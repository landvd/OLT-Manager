# Feishu 查询修复摘要（2026-08-06）

本文记录本轮 Feishu 机器人查询修复，详细合同和边界以 `ARCHITECTURE.md`、`docs/design/api.md` 与 `docs/decisions/ADR-009-feishu-read-only-data-gateway.md` 为准。

## 已修复行为

- 候选查询最多保留 100 条，每页展示 5 条；候选卡片支持上一页、下一页和候选选择。
- 候选分页与选择继续使用五分钟一次性绑定，并重新校验当前聊天和已启用 OLT 范围。
- 姓名或地址查询没有命中、且查询词是短中文短语时，应用层回退到 PON 台账地址搜索。该规则用于覆盖地址简称，不改为无界的任意模糊搜索。
- 唯一用户的 ONU 详情读取失败时，先尝试通用实时状态；若精确坐标仍未被 OLT 返回，则显示本地用户快照资料，并标注“实时 ONU 数据未返回”。
- 降级卡片保留姓名、电话、装机地址、一级地址和 ONU 坐标等已有资料；实时状态、光功率、距离等无法确认的字段显示为未知，不进行推断。

## 只读与数据边界

- 查询仍只允许单聊，自动使用全部已启用 OLT。
- PON 整口状态仍限制为精确 PON 坐标和最多 128 个 ONU，只返回状态、光功率、坐标及允许的快照姓名。
- 本轮没有新增设备写操作、NMSE 同步操作、任意 Telnet/SSH 命令或配置保存路径。
- 文档和日志不得记录真实 OLT 地址、community、账号、密码、Cookie、Token 或完整现场台账。
