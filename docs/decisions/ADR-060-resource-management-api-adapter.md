# ADR-060：资源管理请求适配器

- 状态：已接受
- 日期：2026-08-20

## 决策

桌面端资源管理配置、登录、退出和 VLAN 同步请求统一通过
`src/resource-management-api.mjs` 发出。适配器只负责固定端点和请求体边界，
不访问 DOM、设备、SQLite 或会话内部状态。

配置保存只允许转发服务器地址、用户名、登录密码和迁移主密码四个字段；
密码仍只存在于当前请求体和服务端安全存储流程中，适配器不记录响应或凭据。

## 取舍

`main.js` 继续保留加载状态、按钮状态、登录成功提示和会话失效处理，
因此本次拆分不会改变用户交互和错误文案。后续可按相同边界拆出网管二期
资源请求，但必须继续维持凭据不进入日志和普通状态快照的约束。
