# ADR-073：Feishu 历史光功率的远端优先与本地只读回退

- 状态：Accepted
- 日期：2026-08-20
- 范围：Feishu ONU 详情卡片的“ONU 历史光功率”回调

## 背景

网管二期历史光功率需要使用已登录的只读会话和精确 ONU 坐标。会话失效、远端接口不可用或现场网络异常时，原流程直接返回通用错误，即使本地已经保存了可展示的 `onu_status_history` 也无法帮助用户判断设备状态。

## 决策

1. 详情卡片点击历史光功率时，优先调用现有网管二期只读历史接口。
2. 远端调用失败且本地历史读取接口存在时，回退读取该 ONU 最近 7 天的本地历史。
3. 回退不刷新远端、不写入 OLT、不修改本地历史；卡片根据 `source` 区分网管二期远端结果和本地历史结果。
4. 远端和本地都不可用时，仍返回原有安全错误，不泄露远端响应、凭据或会话信息。

## 取舍

本地回退数据不等同于实时远端结果，因此只能作为历史参考。卡片必须显示来源和日期范围，不能把回退结果标记为“实时查询”。
