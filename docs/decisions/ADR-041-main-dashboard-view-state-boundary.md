# ADR-041：主界面概览视图状态边界

日期：2026-08-19

状态：已接受

## 背景

`src/main.js` 的 Vue `setup()` 同时管理请求、生命周期、设备交互和多个页面的展示映射。首页概览指标、待处理事项、最近状态及 ONU 空状态文案只依赖输入数据，继续内嵌会增加后续页面拆分的耦合。

## 决策

新增 `src/dashboard-view-state.mjs`，抽取首页和 ONU 列表的纯展示映射函数。模块不访问 Vue 响应式对象、DOM、localStorage、网络或 Electron IPC；`main.js` 仍负责 computed 生命周期和数据加载。

## 约束

- 保留原有中文文案、字段和状态 tone，避免把展示拆分变成业务规则变更。
- 缺省计数统一按 0 展示，避免页面在数据尚未加载时出现 `undefined`。
- 运行时间继续复用现有 `formatUptime`，不新增时间解析逻辑。

## 验收

专项测试覆盖首页指标、健康状态、待处理事项、ONU 摘要和空状态文案；全量测试与构建作为合并门禁。
