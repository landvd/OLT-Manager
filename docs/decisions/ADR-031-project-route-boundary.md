# ADR-031：项目管理 HTTP 路由边界

## 状态

已接受，架构七期第 38 项（2026-08-19）。

## 决策

新增 `src/project-routes.mjs`，通过依赖注入承载项目管理 API 的路径匹配、请求体读取和 JSON 响应编排，覆盖项目与项目 ONU 的列表、创建、更新、删除和备注操作。模块返回 `handled` 布尔值：匹配并处理请求时返回 `true`，其它路径返回 `false`，由 `src/server.mjs` 在原项目路由位置短路调用。

模块只接收项目数据库函数、`readBody`、`json` 和当前 OLT 列表；项目 ONU 列表依旧调用现有 `listProjectOnus(projectId, olts)`，因此状态刷新仍使用原有只读设备读取实现。数据库校验、写入、设备读取、认证和其它 API 路由继续留在原边界。

## 兼容与回滚

保留原路径、HTTP 方法、URL 参数、ID 解码、请求体读取时机、成功响应字段、错误状态码和错误响应字段。GET 项目列表未捕获异常的行为也保持由 `server.mjs` 外层错误处理。回滚时删除该模块、专项测试和本 ADR，并恢复 `server.mjs` 原项目路由区；不涉及数据库迁移或设备操作。

## 验证

`tests/project-routes.test.mjs` 使用注入的假依赖覆盖八条项目/项目 ONU 路由、查询参数、请求体、URL ID 解码、OLT 列表传递、错误响应和未匹配返回值。
