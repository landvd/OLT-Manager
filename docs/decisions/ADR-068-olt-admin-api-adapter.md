# ADR-068：OLT 管理请求适配器

## 状态

已接受（2026-08-20）。

## 背景

OLT 管理页面仍在 `main.js` 直接组装列表与保存请求，并同时处理编辑态和服务端响应。该边界扩大时容易把凭据字段、页面字段或错误处理混入请求代码。

## 决策

- 通过 `src/olt-admin-api.mjs` 集中 OLT 列表和保存请求。
- 适配器只依赖注入的认证 fetch，不访问 Vue 状态、SQLite 或设备连接。
- 页面继续负责字段编辑、厂商/型号联动、敏感字段展示控制和保存后的状态同步。
- 服务端仍是凭据脱敏、权限校验和只读/管理操作边界的最终约束。

## 验收

- 专项测试验证固定 GET/PUT 路径、请求体、服务端错误传递和依赖注入失败。
- 全量测试、构建、语法和 diff 检查通过。
