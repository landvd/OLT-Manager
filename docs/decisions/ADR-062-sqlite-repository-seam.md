# ADR-062：SQLite 执行仓储接缝

- 状态：已接受
- 日期：2026-08-20

## 决策

`src/sqlite-repository.mjs` 统一承载 SQLite CLI 调用、串行队列、JSON 查询、执行和
SQL 字符串安全引用。`src/db.mjs` 通过构造函数注入的仓储接口使用这些能力，继续保留
领域 SQL、迁移、备份、恢复和业务映射。

仓储支持注入单次执行适配器，测试可以在不启动 sqlite3 进程的情况下验证队列顺序和查询
解析；生产实现仍使用项目解析出的 sqlite3 路径、请求超时和原有错误信息结构。

## 取舍

本期只移动执行基础设施，不移动领域 SQL，降低迁移风险。后续可以按资源管理、合并 ONU
和项目数据等稳定聚合继续拆出更深的 Repository，但必须让每次拆分都有独立接口和回归测试。
