# ADR-049：真实 OLT 与网管二期只读验证门禁

## 状态

已接受，2026-08-19。

## 决策

现场验证只允许使用已授权的只读 OLT/OSS-NGB 账号和固定查询路径。离线 fixture、协议单测和注入式 adapter 只能证明边界与解析正确，不能证明真实远端路径、权限、坐标映射或历史光功率数据可用。

## 本地门禁

必须通过 OLT 数据网关、SNMP v2c GET/WALK/OID 编解码、OSS/NGB 固定只读请求、历史光功率坐标与日期校验、凭据脱敏和远端未配置时失败关闭测试。禁止以猜测的 URL、命令或凭据进行探测。

## 现场门禁

现场只读取一个已授权 OLT、一个 PON 和一个明确 ONU 坐标；记录脱敏的 HTTP 状态/业务结果、坐标、时间范围和数据行数，不保存密码、Cookie、token 或原始远端响应。任何写操作、任意 Telnet/SSH 命令和不明路径均不执行。
