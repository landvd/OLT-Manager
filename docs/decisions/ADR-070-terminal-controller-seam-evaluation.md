# ADR-070：内置 Telnet 控制器 seam 评估

## 状态

暂不拆分（2026-08-20）。

## 评估对象

`main.js` 中的内置 Telnet 控制逻辑包括 xterm 实例挂载、FitAddon 尺寸同步、终端 DOM 键盘拦截、Electron IPC 会话创建/输入/关闭、Vue 响应式状态和配置方案预览后的安全校验命令追加。

## 结论

当前不创建独立终端控制器。若抽取，接口至少需要传入终端 host、xterm 运行库、会话状态、选中 OLT、配置方案、状态回调、DOM 事件回调和 Electron IPC，接口几乎复述实现，属于浅适配器。

## 后续条件

- 先将终端 UI 变成独立 Vue 组件，或
- 先将 Electron preload 的终端 IPC 收敛成独立接口，或
- 先将配置预览校验命令追加抽成独立纯模块。

满足任一条件后，再重新评估终端控制 seam。
