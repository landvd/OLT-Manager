# ADR-072：服务端 HTTP 请求处理顺序模块

## 状态

已接受（2026-08-20）。

## 决策

- 通过 `src/server-request-handler.mjs` 集中 HTTP 请求的安全顺序：认证路由、普通 API 会话认证、API 分发、静态文件和错误响应。
- 模块接收认证、路由、静态文件和 JSON 响应实现作为依赖，不创建数据库、设备连接或认证策略。
- `startServer()` 继续负责监听地址、初始化数据库/调度器、非回环安全门禁和关闭生命周期。

## 不变量

- `/api/auth/*` 不经过普通 API Bearer 检查，但仍由认证路由模块按路径处理。
- 其他 `/api/*` 必须先通过认证，失败返回 401 和 `www-authenticate: Bearer`。
- 非 API 请求才进入静态文件处理。
- 未捕获错误统一转换为带状态码的 JSON 响应。
