# ADR-054：合并 ONU 同步运行时深模块

## 状态

已接受，2026-08-20；2026-09-11 补充长任务租约心跳与提交守卫。

## 决策

新增 `src/merged-onu-sync-runtime.mjs`，把合并 ONU 同步的运行时编排从 `src/server.mjs` 移出。模块负责：

- 备份优先、幂等键和单 worker 租约；
- 网管二期/NMSE-PON 两类只读源采集及进度更新；
- source manifest 校验、手动合并和全量合并；
- 恢复阶段、失败审计和远端会话失效收敛。

首次 BOSS 历史姓名初始化可能运行数小时，不能把“30 分钟租约”误当作整个任务的最大运行时间。当前 worker 从任务开始或恢复后启动专用心跳，按不超过租约三分之一的间隔调用 SQLite 原子续租；续租只更新 `lease_until/updated_at`，不覆盖 phase/checkpoint。成功、失败和异常路径均停止心跳。新任务通过 `BEGIN IMMEDIATE` 下的条件插入原子获取全局运行槽，不能依赖进程内“先查后写”；源审计与统一数据集提交以同一 `run_id` 幂等，同一运行在业务提交后、运行态完成前中断时可安全重放而不重复换 revision。姓名目录、网管二期源和统一快照提交前必须主动续租并确认 worker 仍持有未过期租约；失权时保持失败关闭。

HTTP 入口只注入数据库、远端客户端、同步服务和状态容器，并暴露同步状态与三个操作接口。该拆分不增加 OLT 写操作、不开放部分数据集替换，也不让密码、Cookie、token、CUID 或原始远端响应进入状态/API。

## 接缝与验证

同步状态、数据库函数、远端会话和合并算法均通过依赖注入；专项测试覆盖成功源同步、备份/源替换顺序、状态投影、跨进程竞争收敛、确定性心跳、失权提交阻断、同运行提交重放及定时器清理。SQLite 集成测试覆盖全局唯一有效租约、同 worker 到期前续租、到期后拒绝和过期恢复。真实 NMSE/OSS-NGB 长时运行和发行包行为仍属于现场/发行门禁。
