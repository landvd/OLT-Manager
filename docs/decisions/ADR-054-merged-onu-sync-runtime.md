# ADR-054：合并 ONU 同步运行时深模块

## 状态

已接受，2026-08-20。

## 决策

新增 `src/merged-onu-sync-runtime.mjs`，把合并 ONU 同步的运行时编排从 `src/server.mjs` 移出。模块负责：

- 备份优先、幂等键和单 worker 租约；
- 网管二期/NMSE-PON 两类只读源采集及进度更新；
- source manifest 校验、手动合并和全量合并；
- 恢复阶段、失败审计和远端会话失效收敛。

HTTP 入口只注入数据库、远端客户端、同步服务和状态容器，并暴露同步状态与三个操作接口。该拆分不增加 OLT 写操作、不开放部分数据集替换，也不让密码、Cookie、token、CUID 或原始远端响应进入状态/API。

## 接缝与验证

同步状态、数据库函数、远端会话和合并算法均通过依赖注入；专项测试覆盖成功源同步、备份/源替换顺序、状态投影和并发运行保护。跨进程租约、真实 NMSE/OSS-NGB 和发行包行为仍属于现场/发行门禁。
