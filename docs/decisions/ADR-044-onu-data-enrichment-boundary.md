# ADR-044：ONU 数据领域编排边界

日期：2026-08-19

状态：已接受

## 决策

新增 `src/onu-data-enrichment.mjs`，通过依赖注入承接 ONU 只读行与本地资源快照、项目分配和项目 ONU 实时状态的合并编排。SQLite 访问、SNMP/Telnet 读取和 HTTP 路由继续由原模块负责。

## 安全与一致性约束

- 资源用户和项目字段只附加到返回副本，不修改设备读取原始行。
- ONU 索引必须是四段数字坐标；不符合格式的快照不会被错误关联。
- 项目 ONU 实时读取失败时保留加入项目时的本地快照，并返回稳定的刷新错误说明。
- 不新增 OLT 写操作，也不把凭据、会话或原始远端响应放入投影。

## 验收

专项测试覆盖资源用户关联、项目分配、缺失 OLT/实时读取失败快照保留和索引规范化；全量测试与构建作为合并门禁。
