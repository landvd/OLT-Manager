# ADR-063：资源管理页面状态模块

- 状态：已接受
- 日期：2026-08-20

## 决策

资源管理页面的配置投影、网管二期登录成功和退出状态转换集中到
`src/resource-page-state.mjs`。该模块只接收普通响应数据并返回有限状态投影，
不访问 Vue、DOM、网络、设备、SQLite 或凭据存储。

所有密码和迁移主密码在投影中被清空；登录结果只保留公开的凭据状态、会话状态和
已脱敏 OLT 列表。`main.js` 继续负责请求、加载状态、自动登录判定、错误提示和生命周期。

## 取舍

本期先拆状态协调 seam，不把动作流程整体搬离页面入口，避免改变 Element Plus 交互和
认证失效处理。后续页面控制器应复用该模块，不直接复制状态投影逻辑。
