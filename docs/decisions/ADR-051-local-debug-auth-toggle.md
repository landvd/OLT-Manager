# ADR-051：本机调试登录保护开关

## 状态

已接受，2026-08-19。

## 决策

本地登录保护默认开启。已完成一次有效登录后，用户可在桌面页面顶部关闭登录保护，以减少本机调试时反复输入至少 8 位密码；该状态持久化在本地 `auth.json`，不会保存密码明文。

关闭保护只对回环监听有效。服务尝试监听非回环地址时，即使本地配置已关闭保护，也必须失败关闭；重新开启保护会立即清除当前 Bearer 会话并要求重新登录。

## 使用边界

该开关只解决 OLT Manager 本机管理页面的登录，不影响网管二期、NMSE-PON、Feishu 或 OLT 设备自身的账号密码。关闭后只建议用于本机调试，不应将服务改为局域网监听。
