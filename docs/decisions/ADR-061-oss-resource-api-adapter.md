# ADR-061：网管二期资源 API 适配器

- 状态：已接受
- 日期：2026-08-20

## 决策

桌面端网管二期配置、登录、退出和历史光功率请求统一通过
`src/oss-resource-api.mjs` 发出。适配器只负责固定端点、字段白名单和请求体，
不访问 DOM、设备、SQLite 或远端会话对象。

配置保存只转发五个非敏感配置字段；登录请求只转发当前输入的密码、迁移主密码和
两个布尔选项；历史光功率请求只转发已由详情状态模块构造的 OLT/ONU 坐标和日期范围。
适配器不记录凭据、不返回原始远端响应，也不改变历史光功率“只读取已保存记录”的边界。

## 取舍

`main.js` 继续负责自动登录判定、密码输入清理、加载状态、会话失效提示和历史结果展示。
这样可以降低入口文件耦合，同时保留真实网管二期路径尚未完全确认时的安全失败行为。
