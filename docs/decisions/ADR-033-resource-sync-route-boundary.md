# ADR-033：资源同步任务路由边界

## 状态

已接受，架构九期第 42 项（2026-08-19）。

## 决策

新增 `src/resource-sync-routes.mjs`，通过依赖注入承载资源同步任务的列表、创建、取消和删除路由。模块只负责 HTTP 路径匹配、输入校验、任务 ID 解码、调度器调用和响应编排；任务持久化、远端会话、用户同步和定时器实现继续由数据库、远端访问运行时和调度器提供。新任务按 `network`、`nmse`、`merge`、`full` 四种同步类型创建，不再选择 OLT。

创建任务仍要求未来执行时间、有效同步类型和 0-365 的整数重复间隔；取消只允许 pending 任务，删除保留对 running 任务的保护。未匹配路径返回 `false`，由服务端继续处理其它路由。

## 兼容与回滚

保留原路径、方法、错误状态码、校验文案、任务状态变更和调度器时机；不改变数据库表、同步算法、远端会话或 OLT 只读边界。回滚时删除该模块和测试，并恢复 `server.mjs` 原任务路由区。

## 验证

`tests/resource-sync-routes.test.mjs` 覆盖列表、创建、调度、时间校验、取消、删除和未匹配路径；服务端完整测试继续验证真实 API 兼容性。
