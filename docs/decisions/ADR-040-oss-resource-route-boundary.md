# ADR-040：网管二期资源路由边界

日期：2026-08-19

状态：已接受

## 背景

`src/server.mjs` 中的网管二期资源配置、登录、字段诊断和历史光功率路由同时包含路径匹配、响应脱敏、会话失效清理、远端只读查询和本地配置保存编排，继续留在入口文件会增加后续服务端拆分的冲突面。

## 决策

新增 `src/oss-resource-routes.mjs`，通过依赖注入承接上述 HTTP 编排。数据库配置、OSS/NGB 客户端、合并目标选择和远端查询实现继续留在原模块；该路由模块不新增写 OLT 能力，也不持久化密码、会话或原始远端响应。

## 保留的安全边界

- 登录返回只使用 `publicOssOlts` 投影，不返回密码、Cookie、token 或原始远端响应。
- 401 只清理 OSS/NGB 会话；配置保存和登录失败继续清理对应会话。
- 历史光功率继续使用已注入的固定只读 OSS/NGB 查询，不猜测远端路径。
- 字段诊断搜索值限制为 1-200 个字符，未登录或远端失败时保持原错误状态码。

## 验收

专项测试覆盖配置投影、登录参数、字段诊断、401 清理、坐标映射、历史光功率和未匹配路由；全量测试和构建作为合并门禁。
