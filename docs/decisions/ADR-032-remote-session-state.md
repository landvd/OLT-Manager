# ADR-032：远端会话状态容器

## 状态

已接受，架构八期第 40 项（2026-08-19）。

## 决策

新增 `src/remote-session-state.mjs`，由服务端宿主创建单一实例，集中保存 NMSE-PON 会话、网管二期会话以及跨平台凭据迁移期间使用的迁移主密码。容器只提供明确的读取、设置和清理方法，不提供可序列化快照，也不写入 SQLite、备份、HTTP 响应或日志。

`server.mjs` 的登录、远端协议和数据库实现保持原位置；所有会话失效、备份恢复、配置变更和退出操作改为调用容器的清理方法。NMSE-PON 会话、网管二期会话和迁移主密码可以独立失效，避免为了刷新一个远端会话而意外扩大清理范围；显式退出或宿主终止时可使用 `clearAll()`。

## 兼容与回滚

保持现有登录路径、401 失效语义、自动重登录逻辑、配置保存语义和远端只读边界。回滚时删除该模块和测试，并将 `server.mjs` 中的容器调用恢复为原有的进程内变量；不涉及数据库迁移和远端接口变更。

## 验证

`tests/remote-session-state.test.mjs` 覆盖空状态、独立清理、全部清理、无效值 fail-closed 以及敏感字段不作为容器公开属性。仍需在桌面重启、真实 NMSE-PON/网管二期登录和跨进程发行包中分别验证会话恢复/失效；本 ADR 不把纯内存容器测试视为现场验收。
