# ADR-084：配置方案编辑器改版、内置方案只读与“生成时填写的参数”

## 状态

已接受（2026-10-10）。

## 背景

配置方案管理的主要用法是：在桌面版编写自定义模板，系统按既有规则自动填入坐标、ONU ID、外层 VLAN 等变量，为未注册 ONU 生成命令预览。现有编辑页存在以下问题：

- 编辑区和预览上下排列；编辑框没有行号、没有变量高亮；变量拼错时没有提示，生成结果里原样保留 `{{xxx}}`。
- 预览样本参数写死，无法试多网口或华为的效果。
- 内置方案可以直接修改，代码中出厂版本的修正不会同步到已有数据库。
- 自定义模板只能使用固定的那几个变量：需要额外参数（例如 ONU 型号、第二个 VLAN）时只能写死；模板的默认内层 VLAN 在界面上改不了，而且生成时会被空输入盖掉。

## 决策

1. **三栏编辑页**：左侧方案列表（“我的方案”在前，“内置方案”可收起），中间编辑，右侧按可修改的样本实时预览并显示检查结果。编辑器带行号和变量高亮（已知变量、生成参数、不认识的变量分三种颜色），输入 `{{` 时自动补全；右键菜单按分组插入变量（生成时填写的参数排在最前），也可以从“插入变量”菜单插入。
2. **模板检查**（`checkConfigTemplate`，前后端共用）：
   - 以下情况算错误，阻止保存，并在生成时阻止生成：不认识的变量（按编辑距离给出建议，可一键替换）、不成对的 `{{ }}`、参数声明有问题。
   - 以下情况只提示：参数声明了但没有用到，模板没有用到 SN 或 ONU ID，ZTE 模板缺少 `show` 核查命令。
3. **内置方案只读**：保存接口拒绝修改内置方案；页面提供“复制为我的方案”。每次启动时，内置方案同步为代码中的出厂版本。若本机在只读之前改过某个内置方案（`updated_at` 与 `created_at` 不同，且命令或默认参数与出厂版本不一致），先把改过的内容另存为一份 `custom-backup-<id>` 自定义方案，再同步。备份只做一次。
4. **生成时填写的参数**（`config_templates.input_params_json`，第 19 版迁移）：
   - 模板可以声明参数，字段为：参数名、显示名、类型（文本 / VLAN / 下拉选项）、默认值、是否必填。
   - 参数名不能和自动取值的变量重名。内层 VLAN 例外，允许改成生成时填写。
   - 生成方案弹窗按声明出现输入框；请求体用 `templateInputs` 提交，缺少必填参数、VLAN 不在 1–4094 或选项不合法时阻止生成。
5. **默认值不被空输入覆盖**：`renderConfigPlan` 只用调用方真正传了值的字段去覆盖模板默认参数。

## 安全边界

只修改本地 SQLite 模板和命令预览的生成；不新增设备命令，不登录、不粘贴、不执行、不保存到 OLT。

## 后果

- 拼错变量或缺少必填参数的模板不再生成带 `{{xxx}}` 或空值的命令；这类情况现在会直接被拦截。
- 内置方案的修正随版本升级自动生效；需要不同写法时，用户维护自己的副本。
- 生成方案弹窗的整体改版（自动生成、分组下拉、精简变量来源等）放在第二批。
