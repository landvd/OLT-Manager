# ADR-045：合并 ONU 同步视图状态边界

日期：2026-08-19

状态：已接受

## 决策

新增 `src/merged-onu-view-state.mjs`，抽取合并 ONU 同步页面的阶段文案、源快照状态、任务状态、进度百分比和日期展示。轮询、请求、Vue 响应式状态合并和错误提示仍由 `src/main.js` 管理。

## 约束

- 网络读取最多映射到 80%，NMSE 分页最多映射到 99%，合并阶段才显示 100%。
- 未知阶段和缺省状态使用原有安全文案，不根据未验证字段推断成功。
- 该模块不访问设备、数据库、会话或 Electron IPC。

## 验收

专项测试覆盖阶段/状态文案、源快照展示和各阶段进度上限；全量测试与构建作为合并门禁。
