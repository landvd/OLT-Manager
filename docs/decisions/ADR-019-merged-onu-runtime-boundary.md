# ADR-019：合并 ONU 同步运行时边界

## 状态

已接受（2026-08-19）

## 决策

将合并 ONU 同步的恢复状态投影、租约判断、快照时间窗口和 source manifest 构造放入 `src/merged-onu-runtime.mjs`。该模块保持纯函数，不读取 OLT/NMSE、不访问 SQLite、不接触凭据、Cookie、token、CUID 或原始远端响应。

`src/server.mjs` 继续负责 HTTP、会话、只读远端适配器和数据库编排；SQLite 中的幂等键、阶段 checkpoint 和跨进程 lease 由 `db.mjs` 的持久化 API 负责。服务端启动时刷新可恢复任务，运行中按阶段续租，完成或失败时清除租约并写入结果。

## 原因

- 先抽取无副作用边界，降低继续拆分 `server.mjs` 时的回归风险。
- 恢复信息只返回稳定的任务标识、阶段和时间，不泄露远端会话材料。
- manifest 的时间窗口和源 revision 在同一处构造，便于后续自动化任务复用。

## 未覆盖范围

本 ADR 不承诺进程崩溃后自动重放远端分页，也不把失败任务静默改成后台自动重试。恢复操作仍需在明确阶段边界上由服务端或人工重新发起；真实多进程压力、桌面重启和现场源数据一致性仍需发行前验证。
