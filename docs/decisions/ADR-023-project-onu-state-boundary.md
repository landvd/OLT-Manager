# ADR-023：项目 ONU 业务状态边界

## 状态

已接受（2026-08-19）

## 决策

将项目 ONU 行归一化、项目列表刷新后的选择、项目 ONU 列表替换和删除后的选择计算放入 `src/project-onu-state.mjs`。`src/main.js` 继续负责 Vue 响应式状态、HTTP 请求、Element Plus 交互、计时器和远端状态刷新编排。

## 依据与边界

这些函数只处理数组和行对象，不依赖 DOM、Vue、网络或设备运行时，可以用 Node 原生测试独立验证。保持现有项目 ONU 字段、`noteDraft`/保存中/移除中 UI 辅助字段，以及刷新和删除后的默认选中行为不变。
