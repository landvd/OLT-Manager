# ADR-050：跨进程生命周期与备份恢复验证门禁

## 状态

已接受，2026-08-19。

## 决策

跨进程能力按 Web 服务、Electron 主进程、CLI 边界和 SQLite 恢复分别验证。纯函数测试通过只证明协议约束，不证明端口监听、进程退出、用户数据目录、发行包资源路径或跨平台恢复。

## 当前保证

- 生命周期启动、并发启动、关闭、强制关闭、启动失败和 CLI abort 均有测试。
- SQLite 迁移可重复执行，备份恢复复用迁移器；加密容器、组合备份、清理 dry-run/显式确认和合并 ONU 恢复均有失败回滚测试。
- 加密备份 API 在本机回环临时服务上通过认证、往返和错误 Content-Type 门禁。

## 待发行环境验证

在 macOS 和 Windows 7 x64 目录包上分别验证启动/退出、重启后的用户数据路径、服务端端口释放、旧数据库迁移、加密 SQLite 导入导出和组合备份回滚。验证失败不得替换现场数据库，也不得清理原备份。
