# ADR-028：备份页面纯状态边界

## 状态

已接受（架构四期 32）

## 决策

将加密备份页面的纯状态逻辑放入 `src/backup-view-state.mjs`，包括加密备份状态初始化、密码字段清理、主密码校验和加密备份文件识别。该模块不依赖 Vue、DOM、网络或 Electron。

`src/main.js` 继续负责 Vue 响应式状态包装、请求编排、下载、确认框和旧 SQLite/桌面组合备份分支。加密备份状态字段保持为 `password`、`confirmation`、`exporting`、`importing`；密码只在当前内存状态和请求期间存在，每条加密导出/导入路径仍在 `finally` 中清理密码字段。

## 依据与边界

本次拆分不改变校验结果、`.sqlite.enc` 和版本化 MIME 识别、请求路径、密码请求头或旧备份行为。后续如需改变密码生命周期、备份格式或恢复编排，应另行更新相应 ADR 和接口测试。
