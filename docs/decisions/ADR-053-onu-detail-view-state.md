# ADR-053：ONU 详情展示状态模块

## 状态

已接受，2026-08-20。

## 决策

新增 `src/onu-detail-view-state.mjs`，承载 ONU 详情页中不依赖 Vue、网络或 DOM 的展示映射：光功率格式化、历史 RX 曲线坐标、只读 service-port 命令预览和 ONU 运行配置预览。

`src/main.js` 继续负责模板、响应式状态、API 请求、Electron/终端生命周期和用户交互；展示模块只返回字符串，不执行任何设备命令，也不改变服务端数据。

## 验证

专项测试覆盖空值/非法光功率、历史曲线最小样本、字段缺失和既有只读命令预览。真实 OLT 数据读取和发行包 UI 仍由现场/发行门禁验证。
