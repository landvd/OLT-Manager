# ADR-096：飞书查 PON 口 / 抢修验收 / 整口状态加“资料有误”，下拉框纠正口的村 / 小组 / 楼盘

## 状态

已采纳（1.3.36）。

## 背景

外勤用“查 PON 口”“抢修验收”（ADR-095）时会发现某个口归错了村、小组或楼盘（小区）。原来只有用户详情卡片上有“资料有误”，要先点进一户，再手打“厚街村/下栅小组”这样的写法，容易写错。

## 决定

1. **入口（三处）**：PON 口清单底部（列当前这页的口）、抢修验收结果概览页（列这次检查过的全部口，复测时为复测的口）、整口状态卡片底部（就是这个口）。
2. **两步表单，全部用下拉框**（卡片 JSON 2.0，原地更新）：
   - 第 1 步：选 PON 口（“PON 1/2/11 · 万达 · 本村82户”）和正确的村（村名列表同 ADR-095，默认是查询的村；整口状态进来时默认是这个口现在归属的村）。
   - 第 1 步同时列出默认村的小组 / 小区（选填，1.3.37 起）：同村不同小组是最常见的错，不用先点“下一步”才看到小组。换了村时第 1 步选的小组作废，第 2 步提示重新选。
   - 第 2 步：口在台账里分路时先选台账行（显示每行现在的归属）；再选“整村（不分小组）”、该村已有的小组 / 小区，或“新小组 / 新小区（楼盘）”并填名称。小组下拉框默认选第 1 步选的小组，没选时默认这个口现在的小组（同一个村时），否则“整村”。
3. **只改村 / 小组 / 楼盘**，不改一级地址（一级地址仍在用户详情的“资料有误”里改）。
4. **沿用资料修改申请（ADR-089）**：提交的是“台账行归属”（`row-place`）申请，发给指定审批人审批，同意后写入按行指定的归属并重算；和现在一样时不提交；同一张表单只能提交一次，24 小时内有效；没有指定审批人时提示。
5. 口不在 PON 台账里时不能按口改，提示到整口状态里点用户，在用户详情上改单户。

## 影响

- 只读写本机 SQLite（申请记录、按行归属），不触发任何 OLT 命令。
- 应该属于本村却没出现在清单里的口，这里选不到，只能从整口状态或用户详情的“资料有误”去改（用户已接受）。
