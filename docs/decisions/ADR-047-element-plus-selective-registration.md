# ADR-047：Element Plus 选择性注册与分包

日期：2026-08-19

状态：已接受

## 决策

`src/main.js` 不再调用 Element Plus 全量插件，而是按模板实际使用的组件从 `element-plus/es/components/*` 直接导入并全局注册；`ElLoading` 作为单独指令注册，消息 API 和全局样式保持可用。

## 验收结果

- 模板组件集合和 `v-loading` 继续通过契约测试。
- 构建转译模块从 1614 降至 1129。
- `vendor-element-plus` JS 从约 773.56 KB 降至约 379.69 KB，gzip 从约 244.63 KB 降至约 119.28 KB。
- 全量测试 381/381 通过，构建通过。

## 后续边界

页面级动态导入仍可作为后续优化，但本决策不改变登录页启动顺序，不引入异步组件加载风险。
