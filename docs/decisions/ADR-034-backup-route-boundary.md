# ADR-034：备份 HTTP 路由边界

## 状态

已接受，架构十期第 44 项（2026-08-19）。

## 决策

新增 `src/backup-routes.mjs`，通过依赖注入承载普通 SQLite 备份、加密备份导出、普通还原和加密还原路由。模块只负责 HTTP 方法/路径匹配、备份响应头、密码头读取、解密后校验顺序和恢复后的远端会话清理；SQLite 导出、迁移校验、原子还原和加密容器实现继续由现有数据库/备份模块提供。

加密还原固定遵循“读取密码 → 读取容器 → 解密 → 校验 → 还原 → 清理远端会话 → 响应成功”，失败只返回稳定错误码/文案，不返回密码、明文备份内容或容器内部字段。普通备份路径和现有 Content-Type/文件名契约保持不变。

## 兼容与回滚

保留现有四条备份 API 的路径、方法、Content-Type、请求大小限制、错误码和恢复后会话失效行为；不改变数据库迁移或备份文件格式。回滚时删除该模块和测试，并恢复 `server.mjs` 原备份路由区。

## 验证

`tests/backup-routes.test.mjs` 覆盖加密导出、解密/校验/还原顺序、普通备份兼容、普通还原错误和缺少密码 fail-closed；既有加密备份 API 测试继续覆盖真实服务端回环行为。
