# ADR-074：历史光功率按需网管二期会话租约

- 状态：Accepted
- 日期：2026-08-20
- 范围：桌面/Web/Feishu 的网管二期历史光功率只读查询

## 背景

历史光功率需要网管二期 OSS/NGB 会话和精确 ONU 坐标。原流程要求用户先手动登录；在 Feishu 场景中，查询本身没有交互机会输入密码，导致历史按钮经常在“未登录”状态下失败。

## 决策

1. 历史光功率入口在确认本机 OLT/IP 映射有效后，复用当前 OSS/NGB 会话；没有会话时调用现有 `loginOssNgbSession({ autoLogin: true })`。
2. 自动登录只读取本机系统加密凭据。没有可解锁凭据时安全失败，不把密码或迁移主密码写入历史查询请求、日志或 SQLite。
3. 自动建立的历史查询会话从成功登录时开始计时，最多保留 10 分钟；租约到期清理会话和 Cookie-bearing client 引用。
4. 同一租约内的并发历史请求共享一个登录 Promise，避免重复登录；已有用户手动登录会话不被历史租约接管或提前退出。
5. 401、配置变更、显式退出、备份清理远端会话和应用关闭均清理租约；当前适配器没有已验证的远程 logout 合同，因此沿用“丢弃本地内存会话”的既有退出语义，不猜测远端路径。

## 取舍

10 分钟租约减少长期 Cookie 留存和 Feishu 后台常驻会话风险，但要求用户首次在桌面端启用本机自动登录，或在 Web/Node 环境提供迁移主密码。该机制不延长网管二期服务器自身的会话 TTL；远端提前失效时下一次查询会重新尝试自动登录。
