# ADR-064：PON 台账请求适配器

- 状态：已接受
- 日期：2026-08-20

## 决策

桌面端 PON 台账查询和保存统一通过 `src/pon-admin-api.mjs` 发出。
适配器集中固定端点、响应数组兼容和错误合同，Excel 导入与页面保存共用同一保存方法。

适配器不访问 Vue、DOM、OLT、SNMP、SQLite 或设备命令；页面继续负责行编辑、筛选、
确认提示、Excel 解析和保存后的响应式刷新。该 seam 不改变本地台账 API 不触发设备命令的约束。

## 取舍

本期只移动请求合同，不移动 PON 行归一化和筛选纯函数，避免把页面编辑状态与网络请求耦合在一起。
