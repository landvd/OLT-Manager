# ADR-036：资源管理读写编排路由边界

## 状态

已接受，架构十二期第 48 项（2026-08-19）。

## 决策

新增 `src/resource-management-routes.mjs`，通过依赖注入承载资源用户查询、地址清理、NMSE 用户完整同步/检查点同步以及 VLAN 查询/同步路由。模块只负责路径匹配、请求体读取、OLT 目标选择、NMSE 会话调用、401 会话失效和响应编排；数据库快照替换、地址清理、分页同步和远端协议实现继续由现有模块提供。

完整同步和检查点同步仍使用原有 `resourceUserSync` 边界，检查点页数继续限制为 1-50；远端 401 只清理 NMSE 会话，不影响网管二期会话或迁移主密码。VLAN 同步仍只调用固定只读 NMSE 接口和本地替换函数。

## 兼容与回滚

保留现有路径、方法、参数、错误状态码、默认查询行为和同步结果字段，不改变数据库写入语义和 OLT 只读边界。回滚时删除该模块和测试，并恢复 `server.mjs` 原资源管理路由区。

## 验证

`tests/resource-management-routes.test.mjs` 覆盖用户查询、同步进度、完整同步、检查点上限、地址清理、VLAN 同步、401 会话失效和未匹配路径；完整 API 回归继续验证真实服务端行为。
