# ADR-069：本地认证请求适配器

## 状态

已接受（2026-08-20）。

## 背景

`main.js` 同时负责认证页面状态和会话恢复、保护开关、登录、初始化数据请求。请求头、固定路径和错误解析分散在生命周期函数中，增加页面拆分时容易出现认证语义漂移。

## 决策

- 通过 `src/local-auth-api.mjs` 集中四个认证请求接口：`session`、`updateRequirement`、`authenticate` 和 `bootstrap`。
- 适配器只依赖注入的认证 fetch，不保存 token、密码或 Vue 状态。
- 页面继续负责密码输入清理、确认框、加载态、登录失效和会话状态更新。
- 密码保护开关的局域网强制认证、服务端权限和 token 清理仍由现有服务端与 `local-auth-client` 负责。

## 验收

- 专项测试验证 Bearer 头、setup/login 路径、开关请求体、错误传递和依赖注入失败。
- 全量测试、构建、语法和 diff 检查通过。
