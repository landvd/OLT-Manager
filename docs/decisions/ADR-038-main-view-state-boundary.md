# ADR-038：主视图纯状态边界

## 状态

已接受，架构十四期第 52 项（2026-08-19）。

## 决策

新增 `src/main-view-state.mjs`，承载主视图使用的纯展示和台账映射函数：ONU 状态/光功率标签、筛选存储键、排序选项、重复地址/状态分组统计，以及 Excel PON 行导入导出。该模块不读取 DOM、localStorage、Vue 响应式对象或网络，不持有用户数据和凭据。

`src/main.js` 保留 Vue 组件、响应式状态、API 调用、终端生命周期和页面事件，只通过导入使用这些纯函数。这样可以在不改变模板和交互的前提下独立验证前端展示边界。

## 兼容与回滚

保持状态文案、光功率分级、筛选键、PON 坐标、Excel 列名和导入过滤规则不变。回滚时删除该模块和测试，并恢复 `main.js` 顶部原纯函数。

## 验证

`tests/main-view-state.test.mjs` 覆盖状态展示、光功率分级、统计、筛选键、排序和 Excel PON 映射；前端生产构建继续验证 Vue 模板入口和静态资源契约。
