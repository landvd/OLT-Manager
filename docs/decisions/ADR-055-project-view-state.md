# ADR-055：项目管理页面纯状态边界

## 状态

已接受，2026-08-20。

## 决策

新增 `src/project-view-state.mjs`，集中项目管理页面的纯展示/编辑映射：新建项目默认表单、已有项目到表单的归一化、提交 payload 清洗和项目 ONU 选中行样式。

`src/main.js` 继续负责 Vue 响应式状态、API 请求、确认弹窗、加载动画、Electron/Web 生命周期和实际 ONU 只读刷新。纯模块不访问 DOM、网络、SQLite 或 OLT，不改变项目删除和项目 ONU 本地关联边界。

## 验证

专项测试覆盖默认值、字符串 VLAN/空字段、输入清洗和选中行映射；真实项目页面和发行包 UI 仍由用户安排的现场/发行门禁验证。
