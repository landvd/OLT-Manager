# ADR-067：ONU 页面请求适配器

## 状态

已接受（2026-08-20）。

## 背景

`main.js` 同时处理 ONU 页面状态和多组固定 HTTP 请求。请求路径分散在加载、详情和配置预览函数中，容易让页面重构重复端点或误改认证/设备边界。

## 决策

- 通过 `src/onu-api.mjs` 集中状态、未注册 ONU、配置模板、ONU 列表、只读详情和配置方案预览请求。
- 适配器只依赖注入的 `request`，不访问 Vue 状态、DOM、SQLite 或设备连接。
- 页面继续负责筛选参数的来源、加载进度、弹窗、错误提示和选中 OLT；认证与 `oltId` 补充仍由现有 `api` 请求边界负责。
- 配置方案仍是固定 POST 的预览请求，不自动粘贴、不自动执行、不保存设备配置。

## 验收

- 专项测试验证固定端点、坐标查询、配置预览 POST 和依赖注入失败。
- 全量测试、构建、语法和 diff 检查通过。
