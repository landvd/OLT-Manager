# ADR-058：备份清理跨进程原子锁

## 状态

已接受，2026-08-20。

## 决策

显式备份清理在备份目录创建 `.backup-cleanup.lock` 原子锁。锁创建使用排他方式，活跃的其他进程会返回稳定的 `BACKUP_CLEANUP_LOCKED` 错误；确认进程已退出且锁超过一小时的陈旧锁可被回收。删除流程用 `finally` 释放当前 owner 的锁，锁内容只包含 PID、时间和随机 owner 标识。

定时任务继续只生成 dry-run 计划，不获得删除锁，也不自动确认删除。锁竞争、陈旧锁恢复和删除后清理均不改变备份候选的完整性校验、路径约束和二次计划校验。

## 验证

备份运行时专项测试覆盖活跃锁 fail-closed、死进程陈旧锁恢复和成功后锁释放；真实多进程发行包行为仍保留在发行门禁。
