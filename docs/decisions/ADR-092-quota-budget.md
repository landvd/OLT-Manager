# ADR-092：定额预算（飞书定额模式与预算书生成）

## 状态

已接受（2026-10-15）。规则已与用户逐条核对，并用现场预算书、管道工程量计算器验证过计算结果；桌面页面与飞书定额模式已实现；说法理解按“学到的说法 → 本地规则 → 拿不准时问大模型”，见设计文档 4.2。

## 背景

- 装维/设计做小工程预算时，要在《广东广电网络工程预算书编制程序》（.xls，带 VBA 宏）里逐条点选定额、手填数量，管道工程量还要先在《管道工程量计算器》里算一遍，材料价格再去《项目立项&设计材料单价参考》里查。
- 预算书要交规建部门审核，**格式不能变**，只能往里填数据。
- 用户希望在**手机飞书**里用说话的方式录入（例如“3 个光缆端开缆”“架空敷设 24 芯光缆 200 米”“24 芯光缆 800 米”），由程序算好并生成预算书；桌面版也能做同样的事。
- 这项功能与 OLT 设备无关，只读写本地文件和 SQLite，不触发任何设备命令。

## 决策

### 1. 三份资料的角色

| 资料 | 用途 | 更新方式 |
| --- | --- | --- |
| 预算书模板（用户用 WPS/Excel 把 .xls **另存为 .xlsx**） | 生成预算书的底板；其中的“定额数据库”表是定额库 | 桌面导入；换新版定额库 = 导入新模板 |
| 项目立项&设计材料单价参考（.xlsx） | 表四甲供的物料与价格 | 桌面导入，每几个月一次，**整份替换** |
| 管道工程量计算器（.xlsx） | 只取其公式，移植成代码 | 不导入；规则见设计文档 |

- 不使用模板里的“定额数据库（导出）”（旧版）和“辅材数据库”（不自动生成乙供辅材）。
- 计算器里顶管的定额编号是旧版（2-27/2-28），按当前定额库改为 **YGWG-2-28 顶管 1 孔、YGWG-2-29 顶管增加 1 孔**。

### 2. 预算书生成：只改工作表 XML，其余部件原样保留

- 输出 .xlsx（用户已确认可以交 .xlsx）。生成时把模板当 zip 打开，**只改写需要填数据的工作表 XML**（项目基础信息表、表二、表四甲供，以及被插行影响的引用），其余部件（样式、主题、打印设置、图片等）逐字节不变。已用单价表做往返试验：61 个部件只有被改的那一个变化。
- 用项目已有的 SheetJS 自带 CFB 读写 zip，不新增依赖。SheetJS 社区版直接写文件会丢样式，所以**不用它写**，只用它读。
- **插行**：数据行不够时，在最后一个数据行后整行插入（与宏“新增一行”一致）。新行复制模板数据行的样式和数字格式，表二新行合并 E:F。插行后同步调整：本表与其它表中引用这些行的公式（例如表二合计 `SUM(L6:L10)`、表一对表二合计格的引用）、合并单元格、共享公式范围、打印区域等定义名称、条件格式、数据有效性、`dimension`。删除 `calcChain.xml`，让 Excel/WPS 打开时重建。
- 数据区不写死行号：表二从第 7 行到“人工费用降点数”的前一行；表四甲供从第 7 行到“甲供材料费用合计”的前一行。各项目模板的空行数不同（4 行、7 行都见过）。
- 模板开启了“**以显示精度为准**”（`fullPrecision="0"`），生成后必须保留。所有金额计算都按格子显示的小数位取整，单元格数字格式必须原样复制。

### 3. 计算规则（已与现场表核对一致）

- **表二**（与宏“选中定额条目”一致）：A `=ROW()-6`；B 定额编号；C/D/E 为定额库的项目名称/项目明细/工作内容；G 单位；H 按地区类别取一至四类单价；I `=项目基础信息表!D15`；J `=H*(1+I)`；K 数量（单位为千米时 3 位小数，否则 2 位）；L `=H*K`；M `=J*K`。
- **利旧**：光缆敷设类定额说“利旧”时，H 写成 `=(原价*0.7)`，备注写“利旧”，新旧分成两行；光缆接续、端开缆和皮线光缆不打折。
- **表四甲供**：H 为单价表的合同最高价（含税），G 13%，F `=ROUND(H/(1+G),4)`，J `=F*I`，K `=H*I`；型号只写规格型号，备注写用户说的用途（例如“架空用”），出仓地方留空。
- **管道**：按计算器公式生成一批定额项（开挖、修复、土方、回填、倒运、敷管、顶管、做井、抹面、直埋子管），开挖和敷管一律 1 孔（宽 0.4 米、沟深 0.85 米），顶管按孔数录入长度，施工测量包含顶管长度，土质默认普通土、砂砾土各 50%。
- 芯数分档往上取最近一档（24 芯敷设 → 36 芯以下，24 芯熔接 → 48 芯以下）；米与千米自动换算；每条录入只生成对应的一条定额，不自动附带关联项（管道计算器除外）；一句话说了几条时拆开逐条生成（见第 6 节）。
- 飞书卡片和桌面显示的金额用同一套“按显示精度取整”的规则计算，与打开 Excel 看到的一致。

### 4. 基础信息

- 多套“基础信息模板”，初始内置一套（取自现有预算书的项目基础信息表），以后用户在桌面自行添加，也可以把当前预算另存为模板。
- 新建预算选模板；**必填**项目名称、建设地点、编制人、审核（不取模板值，提供最近填过的名字快捷选）；工程编号始终留空（由规建部门填）；编制日期取新建当天并固定。
- 基础信息所有行之后都可修改。改地区类别时表二全部重新取单价，利旧行重新打折；勘察距离不提供修改，保持模板值。

### 5. 录入方式

- 飞书：菜单进入“定额模式”（新菜单事件），之后这个会话里的消息按定额解析，直到退出。桌面：新页面“定额预算”。两边操作同一份预算。
- 理解顺序：先查“学到的说法”（每次确认加入即记下，直接生效，桌面可删）；再走本地规则（数量、单位、芯数、利旧、管道说法、物料关键词）；本地拿不准时交给“大模型”（与 Gd Agent 共用），模型只能从本地候选池里选编号，**不产生价格**，失败时退回本地候选。
- 每次加入前都回卡片确认：编号、名称、明细、单位、单价、数量、小计。匹配到多个时列候选点选；物料候选“常用物料”排前，同一预算里再说同一种材料沿用上次的选择。
- 生成预算书后，飞书里以文件消息发给用户（新增文件上传与发送能力），桌面可下载。

### 6. 现场试用后的补充决定（2026-10-16，1.3.18–1.3.23）

- **叫法**：界面上表二定额统一叫“人工”，表四甲供材料叫“材料”；生成的预算书工作表名称保持模板原样。
- **以表单为主，说话为辅**：外勤不方便打字，飞书约九成操作靠卡片按钮和表单（＋人工、＋材料、管道、每条的“改”、基础信息修改、删除预算），说话作为补充。桌面同样以点选为主、一页平铺。
- **常用项**：常用人工默认光缆端开缆、架空光缆敷设、管道光缆敷设、光缆接续；常用材料取单价表“常用物料”；所有预算里用过 3 次的自动算常用；桌面可手动设为 / 取消常用（第 32 版迁移 `quota_common_overrides`）。
- **说法修正**（第一次现场日志里一句多条只录一条、数量取错、纠正与撤销都不认）：一句话按逗号 / 分号 / 顿号和“人工：…材料：…”拆开合成一张卡片；“是 X 不是 Y”改上一条数量；“上一步”撤销；人工、材料各自编号；不带数字的提问给清单，闲聊不问大模型。
- **监理费、安全生产费与 OA 提醒**：按模板表五计算监理费（基数 × 3.3% × (1 − 下浮率)，含税 × 1.06）和安全生产费（建安费 × 2%，含税 × 1.09），合计含税计入两者；**人工 + 监理费 + 安全生产费（含税）> 3000** 时提示“项目人工超过 3000，需要上 OA 系统”（桌面红字 + 每次改动弹框，飞书卡片红字）。只用于提示和显示，生成的预算书仍由模板公式计算表一、表五。
- **飞书卡片按手机排版**：表单只留必填项并紧跟“加入”（卡片太长时手机键盘会挡住输入框和按钮）；一排按钮按字数排，3 个一排每个 ≤ 3 字、2 个一排 ≤ 5 字，否则独占一排；“主菜单”回定额模式主界面，只有主菜单能退出定额模式；千米的人工在表单里一律按米填。

## 边界

- 不连接 OLT、不执行任何设备命令；只读写本地 SQLite 和用户导入/生成的文件。
- 不执行模板里的 VBA 宏；生成的 .xlsx 不含宏。
- 不改动模板的固定内容（标题、表头、合计行、公式、样式、打印设置）；只填数据区和基础信息。
- 大模型只拿到用户说的话和本地候选列表，不拿到价格以外的业务数据，也不决定价格。
- 不生成乙供辅材（不用辅材数据库），表三、表五、勘察费保持模板原有公式；程序里算的监理费、安全生产费只用于显示和 OA 提醒。

## 后果

- 现场在手机上就能完成小工程预算，金额规则与宏、计算器、现场手工表一致。
- 新增：定额/物料/预算相关表（第 30 版迁移）、模板与单价表导入、xlsx 局部改写器、飞书定额模式与文件发送、桌面“定额预算”页。
- 风险：xlsx 插行要同步调整多处引用，必须用用户提供的 WPS 另存 .xlsx 模板做端到端测试（打开无修复提示、合计与手工一致）；用户另存的模板到手前，插行逻辑只能用合成样例测试。
- 单价表格式大改（找不到物料编码、价格列）时导入直接报错，不会悄悄导错价格。
