# ADR-043：网管二期历史光功率视图状态边界

日期：2026-08-19

状态：已接受

## 决策

新增 `src/oss-history-view-state.mjs`，抽取历史光功率请求的坐标/日期组装和响应行安全归一化。远端路径、OSS/NGB 会话、登录状态和 HTTP 请求仍由 `src/main.js` 与服务端路由负责。

## 约束

- 缺少 OLT、ONU 或完整日期范围时 fail-closed，不发起远端请求。
- 继续兼容 `board` 与旧 `slot` 字段，避免坐标迁移改变历史查询范围。
- 非数组响应行归一化为空数组，不把原始远端响应直接交给页面。

## 验收

专项测试覆盖坐标字段、`board/slot` 回退、日期校验和响应行归一化；全量测试与构建作为合并门禁。
