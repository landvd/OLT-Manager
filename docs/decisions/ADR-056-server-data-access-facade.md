# ADR-056：服务端 SQLite 数据访问门面

## 状态

已接受，2026-08-20。

## 决策

新增 `src/server-data-access.mjs`，为 `src/server.mjs` 提供显式 SQLite 数据访问白名单。门面只转发已登记的方法，不暴露 `db.mjs` 的 `query`、`exec` 或其他内部实现；SQL、迁移、队列和运行数据仍由 `db.mjs` 负责。

该边界先解决服务端入口与数据库实现的耦合，后续可在不改 HTTP 路由的情况下，把白名单方法继续迁移到项目、备份、同步等 Repository。缺少任何合同方法时启动即失败关闭。

## 验证

专项测试覆盖白名单投影、冻结接口和缺失方法阻断；本轮未改变 SQLite 表结构、迁移版本或业务 SQL。
