# ADR-037：合并 ONU 管理路由边界

## 状态

已接受，架构十三期第 50 项（2026-08-19）。

## 决策

新增 `src/merged-onu-routes.mjs`，通过依赖注入承载合并 ONU 的进度、运行记录、冲突、数据集状态、快照、源同步、手动合并和全量同步路由。模块只负责 HTTP 编排、快照关键词过滤、运行记录路径脱敏、幂等键传递和拒绝带 `oltId` 的部分替换；合并算法、源读取、备份、manifest、lease、SQLite 事务和恢复状态仍由现有服务层提供。

源同步、手动合并和全量同步继续使用各自既有响应字段与稳定错误语义。运行记录只返回备份文件名，不返回本地完整路径；所有涉及全量替换的入口继续 fail-closed 拒绝 `oltId` 参数。

## 兼容与回滚

保留原有 API 路径、请求方法、响应字段、错误状态码、快照过滤规则和备份路径脱敏行为，不改变数据库或远端读取。回滚时删除该模块和测试，并恢复 `server.mjs` 原合并 ONU 路由区。

## 验证

`tests/merged-onu-routes.test.mjs` 覆盖运行记录路径脱敏、快照过滤、幂等键传递、部分替换拒绝和手动合并响应；完整测试继续验证合并数据真实 API、备份优先和恢复边界。
