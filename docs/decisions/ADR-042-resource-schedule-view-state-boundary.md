# ADR-042：资源同步定时任务视图状态边界

日期：2026-08-19

状态：已接受

## 决策

新增 `src/resource-schedule-view-state.mjs`，抽取定时任务同步类型、状态、重复周期、最近结果和创建请求体的纯映射。Vue 状态、HTTP 请求、确认弹窗和任务生命周期仍由 `src/main.js` 管理；同步任务不再在视图层选择 OLT。

## 约束

- 一次性任务强制把 `repeatDays` 映射为 0，避免页面状态误把重复配置提交到服务端。
- 未知状态继续保留原值或使用 `info`，不伪造任务状态。
- 错误文本只在已有任务对象中展示，不新增远端原始响应或敏感字段存储。

## 验收

专项测试覆盖状态文案、Element Plus 类型、重复周期、失败结果和一次性请求体；全量测试与构建作为合并门禁。
