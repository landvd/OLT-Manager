# OLT Manager 架构整治与功能增强计划

## 目标

在新分支 `codex/architecture-hardening-20260819` 上，按最小冲突的独立任务修复已确认的架构风险，并增加登录界面、Win7 托盘图标、Feishu ONU 设备号/搜索/帮助，以及可验证的网管二期历史光功率实时查询能力。

## 约束

- 保持 OLT 只读边界：不增加 SNMP set、ONU 注册/删除/重启、自动下发配置或任意 Telnet/SSH 命令。
- 不打印、提交或写入真实凭据、Cookie、token、CUID、现场用户资料。
- 优先使用现有 OSS/NGB 固定只读适配器和 `OltDataGateway` seam；不猜测未知远端接口路径。
- 子任务使用 5.6 Luna，写入范围互不重叠；主线程负责安全整合、冲突处理和最终验证。
